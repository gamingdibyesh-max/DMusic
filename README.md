
# 🎵 DMusic

A modern, futuristic music web app focused on music discovery, playback, playlists, lyrics, recommendations, and a smooth mobile-first experience.

## ✨ Features

- 🔎 Professional music search
- ▶️ Music playback
- 🎧 Mini player & full-screen player
- 📱 Mobile-first responsive UI
- 🎵 Playlists & favorites
- 🕘 Recently played
- 📝 Lyrics support
- 🤖 Music recommendations
- 🎶 Queue management
- 🎛️ Media Session API support
- 🌐 Multiple music API integrations
- 👥 Listen Together
- 🌙 Modern dark UI
- ⚡ PWA-ready

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Web APIs
- Music APIs
